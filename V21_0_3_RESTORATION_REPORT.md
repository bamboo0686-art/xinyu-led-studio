# V21.0.3 Media Transform + Irregular Device Restoration

## Restored media controls
- X / Y offset
- Independent width / height
- rotation
- cover / contain / fill
- opacity
- brightness
- contrast
- saturation
- video ±5 sec
- playback speed
- mute
- reset transform
- remove media

## Restored irregular device
- Irregular device preset
- trapezoid
- diamond
- hexagon
- triangle
- octagon
- custom 6-point preset
- custom polygon point input

## Design principle
These features are contextual: they only appear when the selected device actually needs them, instead of occupying the UI all the time.
