# Xinyu LED Studio V3.9｜實景 LED 建模核心修復版

開發單位：心禹國際開發科技有限公司

## 本次找到的真正故障原因
V3.8 的 `createModelSafe()` 會呼叫：
- `presetObject()`
- `safeSceneCenter()`

但這兩個核心函式在前面版本重構時已經遺失，因此使用者按 LED 模型時實際會發生 ReferenceError，模型根本無法建立。

V3.9 已重新建立完整模型工廠與場景中心計算。

## V3.9 建模方式
現在共有四種方式：

1. **點擊左側 LED 模型卡片**
2. **拖曳模型卡片到實景工作區**
3. **心禹工作台「快速建立 LED」**
4. **雙擊實景空白位置**：直接建立一面常規 LED

## 實景座標修正
- 所有新模型使用同一套場景座標系。
- 點擊建立：自動建立在目前實景中央。
- 拖曳建立：模型中心直接落在滑鼠放開位置。
- 建立後自動限制在實景邊界內，避免模型建立到畫面外。
- 建立後立即選取，右側屬性可直接修改。
- 模型大小會依場景尺寸與實際寬高比例產生合理初始大小，不再出現極小或看不到。
