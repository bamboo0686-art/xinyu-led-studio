# 心禹 LED 虛擬播放器 V14

## 1. 一境光幕屏正面面對面修正
- 一境光幕屏維持6支。
- 左側3支、右側3支。
- 左側LED正面朝向中央。
- 右側LED正面朝向中央。
- 修正上一版背面互相面對的問題。
- 中央展示距離維持加寬。
- 6支同步播放同一部影片。

## 2. 自訂真實場景
- 新增場景圖片及影片匯入。
- 可匯入婚宴會場、宮廟、廟會、展覽、戶外活動、商場或客戶現場。
- 圖片會作為大型場景背景。
- 場景影片會靜音循環播放。
- 可搭配原有室內、白天、夜晚、婚宴與宮廟預設場景。

## 3. 設備自由移動
- 新增「開啟自由移動」按鈕。
- 開啟後可直接拖曳設備。
- 一境光幕屏6支可逐支移動。
- 三境光幕屏2組可逐組移動。
- 三面LED精神堡壘2組可逐組移動。
- 移動範圍限制在模擬地面內。
- 新增「重設設備排列」按鈕，可恢復預設配置。
- 移動模式關閉後恢復3D旋轉與縮放。

## 保留功能
- 全螢幕播放。
- 螢幕錄影與WebM輸出。
- 圖片與影片內容匯入。
- 多設備同步播放。
- 外向無縫三面同屏。
- 90度轉角防閃爍。
- 三境高度2公尺。
- 三面LED精神堡壘高度4公尺。
- 頂部與左右無黑框。

## 覆蓋更新
將以下檔案覆蓋上一版本：
- index.html
