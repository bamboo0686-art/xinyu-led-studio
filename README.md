# Xinyu LED Studio V3.4｜影音播放與工作區輸出強化版

開發單位：心禹國際開發科技有限公司

## 1. 影片播放流暢度
- 優先使用瀏覽器 `requestVideoFrameCallback()`，只有影片真的產生新畫格時才刷新 Canvas。
- 不再用固定 30fps 空轉輪詢整個工作區。
- 不支援 `requestVideoFrameCallback()` 的瀏覽器，才退回約 24fps 更新。
- 影片 preload 改成 metadata，降低一開始載入造成的卡頓。
- 保留 requestAnimationFrame 節流繪製與 1.5 DPR 上限。

## 2. 音效／背景音樂
新增：
- MP3 / WAV / M4A / AAC / OGG 上傳
- 播放／暫停
- 音量
- 靜音
- 循環播放
- LED 影片原音開關
- Web Audio 混音架構

背景音樂與 LED 影片原音會進入同一個音訊混音器，供工作區播放與錄製使用。

## 3. 場景大小調整
新增：
- 場景寬度 px
- 場景高度 px
- 鎖定原始比例
- 套用場景大小
- 完整顯示場景
- 恢復原始比例
- 1920×1080 快速設定

場景尺寸影響編輯座標系與工作區輸出，不會修改原始照片檔。

## 4. 編輯工作區影音輸出
新增「編輯工作區影音輸出」：
- 錄製背景場景圖片
- 錄製 LED / LCD 圖片
- 錄製 LED / LCD 影片畫面
- 混入背景音效／音樂
- 可選擇錄製時自動播放全部工作區影片與音效
- 輸出 WebM（影像＋音訊）

## 建議影片格式
為了最佳瀏覽器播放效能：
- MP4：H.264 + AAC
- WebM：VP8/VP9 + Opus

4K、高碼率 HEVC/H.265 或手機特殊編碼影片，在瀏覽器 Canvas 合成時仍可能較吃效能，建議先轉成 H.264 MP4。
