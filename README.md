# 心禹 LED 虛擬播放器 V9

## 三面 LED 精神堡壘
- 顯示高度調整為4公尺。
- 左、正、右三面仍為外向無縫同屏。
- 兩個90度轉角維持共用頂點與連續UV。
- 移除正面、左面與右面全部頂部黑色外框。
- 頂端完整維持LED顯示區域。
- 建議影片展開比例為3:4。

## 三境光幕屏
- 高度維持2公尺。
- 保留頂部外框。
- 建議影片展開比例為3:2。

## 全螢幕播放器
- 新增「全螢幕播放」按鈕。
- 全螢幕內提供「播放／暫停」與「退出全螢幕」按鈕。
- 支援標準Fullscreen API及WebKit前綴。
- 不支援原生全螢幕的手機瀏覽器會自動使用頁面全畫面模式。
- 全螢幕後仍可旋轉與縮放模型。

## 接縫穩定
- 延續索引式共用頂點網格。
- 移除toNonIndexed轉換，轉角不再重新產生重複頂點。
- LED使用不受燈光法線影響的顯示材質，降低90度轉角明暗跳動。
- 背板與LED面保持安全距離。
