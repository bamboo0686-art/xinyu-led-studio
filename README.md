# 心禹 LED 虛擬播放器 V8

## 本版修正：改善左右90度銜接處閃爍

V7在部分顯示卡、手機瀏覽器或旋轉視角下，左右90度轉角可能出現細線閃爍。主要原因包括：

- 轉角相鄰面使用重複座標的不同頂點。
- LED顯示層與內部背板距離太近，造成Z-fighting。
- 外框在部分角度與LED面爭奪同一深度像素。

## V8改善方式

### 1. 共用轉角頂點
- 三面改為索引式單一幾何網格。
- 左側與正面共用同一組轉角頂點。
- 正面與右側共用同一組轉角頂點。
- 轉角不再由兩組重複面片互相貼近。

### 2. LED深度優先
- LED材質啟用polygonOffset。
- LED顯示層使用较高renderOrder。
- 開啟logarithmicDepthBuffer，提高深度精度。

### 3. 背板內縮
- 背板與LED顯示面保持明確距離。
- 背板尺寸略縮，不再碰到轉角邊線。
- 減少Z-fighting與黑色像素穿透。

### 4. 外框避開轉角
- 兩個90度銜接處不設直立黑框。
- 外框只保留整體上下緣及最外側後緣。
- 轉角全區域維持LED顯示。

## 顯示與播放維持
- 影片顯示於ㄇ字型外側。
- 三面是一個連續超寬畫面。
- 左、正、右UV依序為0～1/3、1/3～2/3、2/3～1。
- 只使用一個影片播放器、一個VideoTexture與一條時間軸。
