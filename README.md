# Xinyu LED Studio V20.9.0

心禹國際虛擬 LED 播放器／場景與工程設計工具。

## 啟動

請透過 HTTP(S) 網頁伺服器提供本資料夾，不要直接以 `file://` 開啟。例：

```bash
python -m http.server 8080
```

然後開啟 `http://127.0.0.1:8080/`。首次載入需允許瀏覽器執行 JavaScript；3D 與遠端 AI 功能另需網路連線。

## V20.9.0 重點

- 修復啟動階段未定義變數與素材庫 TDZ 錯誤。
- 修復圖層頁籤選擇器造成的執行期錯誤。
- 統一新專案、場景與背景為 1200 × 1200（1:1），並相容舊專案。
- 修正 1280px 常見視窗下 Dashboard、頂部列與右側檢查器互相遮擋。
- 加強 AI API 超時、HTTPS、回應大小與內容渲染安全。
- 加入 CSP、Permissions Policy、no-referrer 與跨來源快取限制。
- 匯入專案的編號與狀態在 Dashboard 顯示前會安全轉義。
- 新增多設備智慧控制中心：最多一次建立 24 台並自動排列。
- 批次選取、複製、移動、縮放、旋轉、刪除與媒體完整還原。
- 多影片同步播放、暫停、重播、跳轉與循環控制。
- AI 指令支援批次建立、智慧排版、全選與全部播放／暫停。

完整內容請參閱 `V20.9.0_MULTI_DEVICE_REPORT.md`。
