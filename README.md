# 心禹 LED 虛擬播放器 V10

## 本版更新

### 三境光幕屏
- 高度維持2公尺。
- 去除頂部黑色外框。
- 去除左右最外側黑色外框。
- 兩個90度轉角維持無框、無縫LED顯示。
- 僅保留底部必要支撐結構。

### 三面 LED 精神堡壘
- 高度維持4公尺。
- 去除頂部黑色外框。
- 去除左右最外側黑色外框。
- 三面保持外向無縫同屏。
- 僅保留底部必要支撐結構。

### 螢幕錄影
- 新增「開始錄影」按鈕。
- 錄影內容包含播放器3D畫面、影片播放、旋轉與縮放操作。
- 錄影中顯示計時。
- 點擊「停止並儲存」後，自動輸出WebM影片。
- 預設30 FPS、約8 Mbps。
- 支援Chrome、Edge及多數Android瀏覽器。
- 若瀏覽器允許且影片未靜音，會嘗試同步錄製影片聲音。
- iPhone Safari及部分瀏覽器可能僅支援無聲錄影，或不支援Canvas錄影。

### 既有功能保留
- 全螢幕播放。
- 外向無縫三面同屏。
- 單一VideoTexture及同一影片時間軸。
- 90度轉角防閃爍。
- 三境2公尺、精神堡壘4公尺。
- 圖片與影片匯入。
- 電腦與手機旋轉、縮放操作。

## 覆蓋更新
將以下檔案直接覆蓋Repository根目錄中的上一版同名檔案：

- index.html
- manifest.json
- sw.js
- icon.svg
- README.md

更新完成後：
- 電腦按Ctrl＋F5。
- 手機關閉舊頁面後重新開啟。
