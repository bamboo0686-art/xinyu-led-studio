# 心禹 LED 虛擬播放器 V2

## 本版重點
- 三境光幕屏：正面＋左右兩側90°的ㄇ字型
- 三面 LED 精神堡壘：正面＋左右兩側90°的ㄇ字型
- 兩者都是三面，不是兩面，也不是三角柱
- 精神堡壘以較厚框體、加強底座及支撐腳區隔
- 支援電腦與手機瀏覽器
- 支援 MP4、MOV、WebM、JPG、PNG
- 支援旋轉、縮放、亮度、發光與像素紋理

## 更新方式
把本資料夾內五個檔案上傳到既有 Repository 根目錄，覆蓋舊檔案：
`bamboo0686-art/xinyu-led-studio`

網站：
https://bamboo0686-art.github.io/xinyu-led-studio/

上傳後若仍看到舊版，電腦按 Ctrl + F5；手機關閉頁面後重新開啟。
