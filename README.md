# Xinyu LED Studio V3.7｜屬性整合＋多模型＋裸眼3D＋媒體生命週期修正版

開發單位：心禹國際開發科技有限公司

## V3.7 重點

### 1. 把工作區浮動功能移到右側屬性
已把原本工作區上的：
- 複製／刪除
- 場景尺寸
- 縮放比例
- mm / cm / m
- 吸附／格線
- 自動吸附組裝狀態

整理到「屬性」區域。中央工作區保留乾淨的場景與模型。

### 2. 同一場景多個 LED 模型
- 左側模型庫可以連續新增任意數量 LED / LCD / 底座。
- 新增「＋新增同型模型」。
- 每個模型可獨立調整尺寸、Pixel Pitch、內容、亮度、透明度與播放。
- 目前場景模型數量會在屬性區即時顯示。

### 3. 裸眼3D播放預覽
選取 LED 後可啟用：
- 視差推拉
- 懸浮破框
- 景深呼吸
- 3D 深度強度 0～100%

這是編輯器的「裸眼3D效果預覽」。正式L型/U型裸眼3D仍須依實際觀看點、屏幕結構與內容透視製作。

### 4. 刪除影片後仍播放修正
新增完整 Media Lifecycle：
刪除或更換影片時會：
1. pause()
2. 清除 src
3. load()
4. revokeObjectURL()
5. 從物件移除 media
6. 播放引擎在無影片時自動停止

因此刪除 LED 模型或替換影片後，舊影片不應再於背景繼續播放。

### 5. 模型管理
屬性區新增：
- 複製選取模型
- 刪除選取模型
- 新增同型模型
- 置中選取模型
