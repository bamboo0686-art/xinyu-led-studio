# 心禹 LED 虛擬播放器 V6

## 核心訂正：無縫三面同屏

本版不再把三面當成三個獨立顯示器，也不是把同一支影片完整複製到三面。

### 正確顯示方式
- 左側面、正面、右側面共同組成一個完整超寬顯示畫布。
- 影片畫面依序分配至左側、正面、右側。
- 左側與正面的90度轉角為連續LED顯示面。
- 正面與右側的90度轉角同樣為連續LED顯示面。
- 轉角位置沒有黑色框條、間距、斷點或重複畫面。

### 技術方式
- 只建立一個Three.js Mesh。
- 以三組連續四邊形組成ㄇ字型外表面。
- 三面共用同一組幾何接點。
- 使用一組連續UV：
  - 左側面：0～1/3
  - 正面：1/3～2/3
  - 右側面：2/3～1
- 只使用一個VideoTexture與一條播放時間軸。
- 內部轉角不建立直立黑框，只有整體最外圍框體。

### 建議影片比例
三面各寬1公尺、高2公尺，展開總尺寸為3公尺×2公尺，因此建議內容比例為3:2。

例如：
- 1536×1024
- 1920×1280
- 3072×2048
