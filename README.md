# 心禹 LED 虛擬播放器 V16

## 1. LED亮度調整
- 每一台設備可獨立設定10%～200%亮度。
- 亮度直接作用於LED Shader，不會只改變場景整體曝光。
- 不同設備可設定不同亮度。

## 2. 設備滑鼠自由調整
- 新增Three.js TransformControls三軸控制器。
- 移動模式：直接拖曳X、Y、Z軸。
- 旋轉模式：拖曳旋轉環，可任意調整角度。
- 自由變形模式：分別拉伸X、Y、Z軸。
- 可用滑鼠改變設備位置、方向、寬度、高度及側深比例。
- 仍保留數值輸入精準調整。

## 3. 疊加物件滑鼠自由調整
- 新增2D視覺化疊加編輯器。
- 點選文字、圖片或影片後可直接拖曳移動。
- 拖曳右下角控制點可自由改變寬度、高度與比例。
- 數值欄位會與滑鼠操作同步更新。
- 疊加結果會即時同步到所有LED設備與成果錄影。
