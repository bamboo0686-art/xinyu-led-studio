# Xinyu LED Studio V3.2｜拖曳組裝與場景工作流強化版

- LED／LCD／底座模型可直接拖曳到中央工作區。
- 拖曳落點即為設備放置位置。
- 屏體與底座靠近時會自動置中吸附。
- 新上傳圖片／影片可拖到 LED / LCD 上套用。
- 左側模型庫與右側屬性面板均可收合，中央工作區可即時放大。
- 場景流程進一步簡化為：現場照片 → 模型 → 底座 → 素材 → 透視 → 工程 → 3D / CAD / AI。
- 保留 V3.0 / V3.1 既有 AI、3D、三面同步、BOM、Mapping、配電與 CAD 功能。

大型本機影片採工作階段 Object URL，不直接塞入 localStorage；重新開啟瀏覽器後需重新載入大型本機素材。
