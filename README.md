# 心禹 LED 虛擬播放器 V17

## 多行文字與直橫排
- 文字內容改為多行輸入框。
- 支援Enter手動換行。
- 橫式文字可依設定寬度自動換行。
- 可切換直式文字，逐字由上往下排列。
- 疊加編輯器與LED輸出同步顯示。

## LED亮度修正
- 修正亮度滑桿只改變資料但未正確影響畫面的問題。
- 亮度直接控制Shader輸出。
- 範圍提升為20%～300%。
- 預設亮度提高為135%。
- 增加Gamma提亮及環境補光，改善原本偏暗。
- 每台設備仍可獨立設定亮度。

## 不規則LED造型
- 新增不規則輪廓編輯器。
- 點擊新增輪廓節點。
- 拖曳節點任意改變形狀。
- 可刪除節點及重設矩形。
- 可將輪廓套用至選取設備。

## 新增預設設備組合
- L型LED。
- 曲面型LED。
- ㄇ字型LED。
- 圓形LED。
- 原有一境6支、三境2組、三面LED精神堡壘2組繼續保留。
