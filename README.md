# 心禹 LED 虛擬播放器 V11

## 緊急修正版

V10中錄影按鈕已加入HTML，但JavaScript初始化時未正確取得record與recordBadge元素，造成程式在建立模型前中斷，因此一境光幕屏、三境光幕屏與三面LED精神堡壘全部消失。

V11已修正：

- 正確取得錄影按鈕與錄影狀態元素。
- 錄影功能加入防呆，瀏覽器不支援時不會中斷播放器。
- 加入執行錯誤提示區，未來若載入失敗可直接看到錯誤原因。
- 恢復一境光幕屏。
- 恢復三境光幕屏。
- 恢復三面LED精神堡壘。
- 保留全螢幕播放。
- 保留螢幕錄影。
- 保留三境光幕屏頂部與左右無黑框。
- 保留三面LED精神堡壘4公尺高度、頂部與左右無黑框。
- 保留三面外向無縫同屏及90度轉角防閃爍。

## 覆蓋更新

請直接以本版五個檔案覆蓋上一版本：

- index.html
- manifest.json
- sw.js
- icon.svg
- README.md

更新後請按Ctrl＋F5。
