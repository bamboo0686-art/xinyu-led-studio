# Xinyu LED Studio V3.5｜操作核心與影音輸出修正版

開發單位：心禹國際開發科技有限公司

## 本版修正

### 1. 工作區控制移到「屬性」
原本浮在中央工作區的：
- 上傳實景
- 放大
- 100%
- 適合完整場景
- 縮小
- 垂直參考線
- 水平參考線
- 清除參考線
- 全螢幕

已全部移到右側「屬性」工作區控制面板，避免遮住實景畫面。

### 2. 頂部功能真正可用
新增實際選單功能：
- 編輯：復原、重做、全選、複製、刪除
- 檢視：Fit Scene、100%、吸附、格線、全螢幕、3D
- 匯出：直接切換輸出中心
- 設定：專案設定、屬性、提案／施工模式
- 專案：原本專案工作台繼續保留

### 3. 工作區刪除 LED 模型
- 選取模型後工作區出現「複製／刪除」
- Delete / Backspace：刪除
- Ctrl/Cmd + D：複製
- Esc：取消選取

### 4. 影片聲音修正
一般播放不再一開始就把影片音訊強制導入 Web Audio。
因此：
- 平常播放優先使用瀏覽器原生影片聲音
- 播放時強制確認 muted / volume
- 只有在工作區錄影混音時，才把影片接入 Web Audio 混音器
- 保留「播放 LED 影片原音」開關

### 5. 工作區播放畫面輸出影像檔
新增：
- 自動：優先 MP4，瀏覽器不支援時改 WebM
- MP4
- WebM
- 手動停止 / 10秒 / 30秒 / 60秒

錄製內容包含：
- 實景背景
- LED/LCD 圖片
- LED/LCD 播放影片
- 背景音樂／音效
- 影片原音（有開啟時）

### 6. LED 模型建立效能
- 新增模型時不再同步重建所有圖層、BOM、工程統計
- 畫布與屬性先立即更新
- 圖層／BOM／工程統計改成 idle / 延後更新
- 自動儲存延後到 2.8 秒，播放或錄影時不搶資源
- 拖放新增模型也採相同輕量流程

## 建議
影片若要求最穩定的畫面＋聲音，優先使用：
- MP4 / H.264 + AAC
- WebM / VP8/VP9 + Opus
