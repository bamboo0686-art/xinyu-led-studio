# Xinyu LED Studio V21.0.0

心禹國際虛擬 LED 播放器／場景與工程設計工具。

## 啟動

請透過 HTTP(S) 網頁伺服器提供本資料夾，不要直接以 `file://` 開啟。例：

```bash
python -m http.server 8080
```

然後開啟 `http://127.0.0.1:8080/`。首次載入需允許瀏覽器執行 JavaScript；3D 與遠端 AI 功能另需網路連線。

## V21.0.0 重點

- 全面重設專業深色介面、資訊階層與操作回饋，將「心禹工具軌」改為「設備箱」。
- 設備建立後可直接轉換矩形、曲面、L 型、ㄇ型與自由異形，並可增減節點，不必重建。
- 新增設備邊框：可設定開關、寬度、顏色、實線／虛線／點線與透明度，支援批次套用。
- 顯示內容可一次獨立套用到多台選取設備，也可逐台更換或移除。
- 每台設備可獨立設定倍速、音量、靜音、循環與同步時間偏移。
- 多設備支援選取播放、全部同步播放、同步跳轉、暫停、重播與素材複製。
- 裸眼 3D 新增速度、方向、自然／展演／強烈預設、批次套用與暫停控制。
- 移除「工程自動計算」可見介面與背景自動運算；必要底層資料僅保留給 BOM／匯出相容性。
- 合併重複 AI 入口為「AI 視覺指揮中心」，支援設備建立、智慧排列、形狀、邊框、播放與 3D 指令。
- 瀏覽器驗證：Mock E2E 23/23、系統健檢 12/12、按鈕功能 207/207。

完整內容請參閱 `V21.0.0_PROFESSIONAL_DEVICE_STUDIO_REPORT.md`。
