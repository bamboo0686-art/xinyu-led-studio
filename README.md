# Xinyu LED Studio V3.8｜模型建立修復＋工作台整合版

開發單位：心禹國際開發科技有限公司

## 本版修正

### 1. LED 模型無法建立
模型建立核心重新整理為 `createModelSafe()`：
- 預設模型資料檢查
- 場景中心安全計算
- 先寫入場景，再立即顯示
- 屬性與工程計算延後
- 建立數量驗證
- 建立失敗時由 Runtime Guard 攔截，不讓整個程式中斷

模型現在有三種建立方式：
1. 點擊左側模型卡片
2. 拖曳模型卡片到中央場景
3. 心禹工作台「快速建立 LED」

### 2. 工作區控制移到心禹工作台
已從右側屬性移除，整合到左側心禹工作台：
- 上傳實景
- 全螢幕
- 放大 / 縮小 / 100%
- 適合完整場景
- 垂直參考線
- 水平參考線
- 清除參考線

### 3. 場景／座標資訊移到心禹工作台
心禹工作台現在直接顯示：
- 場景尺寸
- 目前縮放比例
- mm / cm / m
- 吸附開關
- 格線開關
- 自動吸附組裝
- 目前場景模型數量

### 4. 快速建立
新增：
- 常規 LED
- 一境光幕屏
- 三境光幕屏
- 三面 LED 精神堡壘

右側「屬性」現在重新專注於選取模型本身的尺寸、內容、效果、工程與裸眼3D設定。
