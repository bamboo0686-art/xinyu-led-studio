# 心禹 LED 虛擬播放器 V12

## 多設備同步展示版

### 一境光幕屏
- 同時顯示6支。
- 預設採3×2排列。
- 6支共用同一部影片、同一VideoTexture與同一時間軸。
- 每支高度2公尺。

### 三境光幕屏
- 同時顯示2組，左右並列。
- 每組高度2公尺。
- 頂部與左右無黑框。
- 2組共用同一影片及同一時間軸。

### 三面 LED 精神堡壘
- 同時顯示2組，左右並列。
- 每組高度4公尺。
- 頂部與左右無黑框。
- 2組共用同一影片及同一時間軸。

### 保留功能
- 全螢幕播放。
- 螢幕錄影及WebM輸出。
- 圖片與影片匯入。
- 3D旋轉與縮放。
- 外向無縫三面同屏。
- 90度轉角防閃爍。
