# Xinyu LED Studio V3.3｜流暢度與播放核心修正版

開發單位：心禹國際開發科技有限公司

## 本版優先修正的四個問題

### 1. 操作卡頓／不順暢
- 2D Canvas 改採 `requestAnimationFrame` 節流重繪。
- 滑鼠拖曳過程不再每一個 pixel 都重建右側屬性 DOM。
- 2D Canvas DPR 上限調整為 1.5，降低 4K／高 DPI 螢幕負擔。
- 影片播放畫面限制約 30fps 更新，避免無限制高頻 redraw。
- 滾輪、拖曳、縮放全部共用同一套輕量繪製排程。

### 2. 編輯工作區完整顯示場景
- 實景照片改為「保持原始比例」顯示，不再強制拉伸填滿。
- 新增真正的 `適合畫面 / Fit Scene`。
- 上傳場景後自動計算比例並置中，完整照片不被裁切。
- 100% 顯示也會自動保持場景置中。
- 全螢幕切換後會重新計算 Fit。

### 3. 滑鼠滾輪
- 一般滾輪：以滑鼠所在位置為中心縮放。
- Shift＋滾輪：水平移動畫布。
- Alt＋滾輪：調整選取 LED 內容縮放。
- 滑鼠中鍵拖曳：快速平移畫布。
- 縮放範圍：5%～800%。

### 4. 播放鍵修正
- 影片不再只呼叫 `video.play()` 而沒有 Canvas 畫面更新。
- 新增影片播放迴圈，播放時 Canvas 會持續同步刷新。
- 新增「影片載入中／已就緒／播放中／暫停／錯誤」狀態提示。
- 上傳影片後不強制自動播放，改由使用者按「播放」控制。
- 支援 MP4 / WebM 等瀏覽器可播放格式。

## 使用提醒
若影片按播放仍失敗，通常是影片編碼不是瀏覽器支援格式。建議優先使用：
- MP4（H.264）
- WebM
