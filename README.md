# 心禹 LED 虛擬播放器

## 使用方式
將本資料夾全部檔案上傳至 GitHub Repository `bamboo0686-art/xinyu-led-studio`，再於 Settings → Pages 設為從 `main` branch 的根目錄部署。

部署後網址通常為：
https://bamboo0686-art.github.io/xinyu-led-studio/

iPhone 請使用 Safari 開啟網站，再選「分享 → 加入主畫面」。

## 建議影片格式
MP4、H.264 影像、AAC 聲音。MOV 能否播放取決於裝置與影片編碼。

## 產品規格
- 一境光幕屏：100 × 200 cm
- 三境光幕屏：三面各 100 × 200 cm
- 三面 LED 精神堡壘：三面各 100 × 200 cm
- 點距：P2.604
