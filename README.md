# 心禹 LED 虛擬播放器 V13

## 一境光幕屏左右對襯展示版

### 一境光幕屏6支
- 左側排列3支。
- 右側排列3支。
- 左右兩排彼此對襯。
- 左側螢幕朝向中央。
- 右側螢幕朝向中央。
- 中央通道加寬，避免設備過度擁擠。
- 預設使用斜上方視角，可同時看見左右兩排與中央展示空間。
- 6支共用同一部影片、同一VideoTexture及同一時間軸。

### 其他產品維持
- 三境光幕屏2組左右並列。
- 三面LED精神堡壘2組左右並列。
- 三境高度2公尺。
- 三面LED精神堡壘高度4公尺。
- 頂部與左右無黑框。
- 外向無縫三面同屏。

### 保留功能
- 全螢幕播放。
- 螢幕錄影。
- WebM輸出。
- 3D旋轉與縮放。
- 圖片與影片匯入。
- 90度轉角防閃爍。
