# 心禹 LED 虛擬播放器 V15

## 新增功能
1. 自由新增設備
- 單面、L型、ㄇ字型、四面柱型。
- 自由設定寬度、高度、側深及設備名稱。
- 可複製、刪除及清空。

2. 自由移動與任意旋轉
- 開啟移動模式後，拖曳設備可移動。
- Alt＋拖曳可任意旋轉設備。
- 亦可直接輸入X、Z位置與旋轉角度。

3. LED像素間距
- 可選P0.78、P0.93、P1.25、P1.56、P1.875、P2、P2.5、P2.604、P2.976、P3.906、P4.808、P6.67、P8、P10、P16.67。
- 自動顯示約像素密度及最短觀看距離。
- 每一個設備可設定不同P值。

4. 疊加文字、圖片及影片
- 可在主影片上疊加文字。
- 可疊加圖片或影片。
- 可調整位置、尺寸與透明度。
- 所有LED設備同步顯示合成後的內容。

5. 成果影片匯出
- 可錄製整個3D模擬畫面。
- 包含場景、設備、主影片、疊加內容、移動及旋轉操作。
- 匯出WebM影片。

6. 真實場景
- 可匯入圖片或影片作為場景。
- 保留一境6支、三境2組、三面LED精神堡壘2組預設配置。
