# Xinyu LED Studio V20.8.3｜Workbench Visibility & Adaptive Layout Hotfix

本版針對使用者實機影片發現的「心禹工作台功能被擠到螢幕底下」進行版面級修復。

## 修正
- 取消底部工作台固定 185px 的舊限制，改為可調高度。
- 預設工作台高度 360px，可拖曳上方金色把手調整。
- 新增縮小／還原／最大化。
- 工作台改為左右雙區：左側工作區控制、右側模型／素材庫。
- 左右區塊各自獨立捲動，不再互相擠壓。
- 修正 dock-collapsed 殘留的舊 4 欄 CSS，恢復目前 3 欄架構。
- 底部狀態列不再蓋住工作台。
- 新增 workbenchVisibilityAudit()，啟動後檢查工作台是否真的在視窗內可見。

## 使用
- 拖曳工作台頂部金色把手：自由改高度。
- ▁：縮小。
- ▣：還原。
- ▰：最大化。
- ◀：只收合左側控制區，不再破壞整體版面。
