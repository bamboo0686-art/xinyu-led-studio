# 心禹 LED 虛擬播放器 V7

## 本版修正：影片完整顯露於ㄇ字型外側

V6的三面幾何頂點順序錯誤，使法向量朝向ㄇ字型內部，因此影片看起來被夾在中間。

V7已修正三面外向法向量：

- 左側面：朝 -X 外側顯示。
- 正面：朝 -Z 外側顯示。
- 右側面：朝 +X 外側顯示。
- ㄇ字型內部不顯示影片。
- 從設備外側可清楚看到三面影片。

## 無縫連續畫面維持不變

- 左、正、右三面仍是一個完整連續Mesh。
- 三面共用同一組幾何接點。
- 轉角沒有黑框、縫隙或畫面中斷。
- 使用一組連續UV：
  - 左側面：0～1/3
  - 正面：1/3～2/3
  - 右側面：2/3～1
- 只使用一個VideoTexture與一條影片時間軸。
- 背板已往ㄇ字型內側縮，避免遮住LED畫面或產生Z-fighting閃爍。

## 建議影片比例

三面展開總尺寸為3公尺×2公尺，建議使用3:2比例：

- 1536×1024
- 1920×1280
- 3072×2048
