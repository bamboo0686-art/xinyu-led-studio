# Xinyu LED Studio V20.0｜Professional Engineering & 3D Edition

開發單位：心禹國際開發科技有限公司

## 本次核心升級
- 最左側正式名稱：心禹工具軌（Xinyu Tool Rail）；第二欄：心禹工作台（Xinyu Workbench）。
- 完整介面顯示：主頁可垂直捲動，各側欄可獨立捲動；另有 100% / 90% / 80% 介面總覽。
- 影片 Timeline：拖曳、指定秒數、±5秒、播放/暫停。
- 實景圖可新增/更換、刪除、旋轉、縮放。
- LED/LCD 可持續新增/刪除，支援角度、工作區旋轉控制點與縮放控制點。
- 影片/圖片可新增/刪除、旋轉、獨立寬度/高度/縮放/位置。
- 曲面 LED 改為真正弧面輪廓；3D 改用 CylinderGeometry。
- 原 U 型正式改為「ㄇ字型」；2D 顯示三面結構，3D 採三面連續幾何與連續 UV。
- V20.0 仍保留實景、BOM、Mapping、CAD、3D、裸眼3D預覽、PWA、IndexedDB、Release Gate。

## 重要
Three.js 目前仍採 CDN。正式完全離線 3D 需後續將 Three.js / OrbitControls vendor 本地化。
