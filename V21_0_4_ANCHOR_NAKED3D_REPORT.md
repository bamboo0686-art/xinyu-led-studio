# V21.0.4 Universal Anchor + Naked-Eye 3D Preview

- All devices: 4 corner anchors (NW/NE/SW/SE)
- All devices: rotation handle remains
- Anchors are mouse/pointer draggable
- Corner anchors resize independently

## Irregular device anchors
- Every irregular polygon vertex becomes a draggable anchor
- Dragging updates shapePoints immediately
- Clip-Path and custom point text update in real time

## Naked-eye 3D video preview
- Dedicated preview modal
- Perspective strength
- Pop-out depth
- Rotate X/Y
- Perspective origin X/Y
- Scale
- Vignette
- Play/Pause
- Reset parameters
